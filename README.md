# 💊 Pharmacy Management System

A pharmacy management application developed using Java, SQLite, and JDBC.

## Features

- 🔐 Pharmacist and manager authentication
- 💊 Medicine management: adding, deleting, and updating prices
- 📦 Stock management and critical stock monitoring
- 🛒 Sales registration, cancellation, and consultation
- 📋 Replenishment order management
- 📊 Stock movement history

## Technologies

- Java
- SQLite
- JDBC
- DAO / Service / App architecture
